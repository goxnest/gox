# CLAUDE.md

## Project

gox is Go plus five additions for API code (decorators, implicit `ctx`, `throw` errors, `parallel`, `@Async`). A translator turns `.gox` files into plain, readable Go ahead of time. The design is in `goxd Build Plan.md`, which uses the old working name *goxd*. Use **gox** in new code and docs.

- Org and repo: github.com/goxnest/gox
- Module path: `github.com/goxnest/gox`
- Status: Phase 0 (spike). `main.go` is a throwaway prototype scanner. `gox/` holds model sketches.

## Commands

```sh
go build ./...
go vet ./...
go test -race ./...
go run . main.gox        # prototype: rewrite @X lines to comments
```

## Rules for changes

- **Superset:** valid Go must pass through the translator unchanged. Never rewrite code outside managed types, which are structs marked `@Controller` or `@Injectable`.
- **Rewrite only what Go rejects:** sugar sites are code that plain Go would not compile.
- **No runtime reflection.** Routes, binding and wiring are generated.
- **The runtime package depends only on the standard library.** Minimum Go version is 1.22.
- **Scanner pass:** keep line numbers stable. It must never change a line that has no sugar.
- **Use Go's packages** (`go/scanner`, `go/parser`, `go/types`, `x/tools/go/packages`) for parsing and type checking, not hand-written parsers.
- **Generated files** are named `*_gox.go`, start with `// Code generated by gox. DO NOT EDIT.`, and use `//line` directives that point back to the `.gox` source.
- **Tests:** add golden pairs under `testdata/golden/` for every translation rule.
- **Scope:** keep to five additions. Anything outside version 1 scope (see the plan) needs discussion first.
